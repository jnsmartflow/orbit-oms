Drafts & Sent — /po vs /po-v2-8f4kd2

Same three orders, rendered by each page's own rules. Only the styling differs. Numbers in the violet circles match the annotation table at the bottom.

Not faithful — read before deciding anything from this page

  1. Typeface, if this machine is offline. The app loads Plus Jakarta Sans and JetBrains Mono through next/font. This page asks Google Fonts for them. With no network it falls back to the system sans and the letterforms, and therefore the apparent width of every line, will be wrong. Sizes and weights are still right.
  2. Tailwind is hand-implemented, not loaded. The class strings on the elements are verbatim from the source; the rules that render them are written out in this file's <style> block. A mismatch between the two would be a bug in this file.
  3. No interaction. active:opacity-70 and active:text-red-500 (v1) are present as strings but inert. Nothing here responds to a tap, and v2's 44px delete target cannot be felt.
  4. v1's icons are lucide-react (Zap, Trash2). Their real path data is inlined, but lucide renders through a React component with its own default attributes; a hair of stroke rendering may differ.
  5. Card 2's name truncation depends on the font. Where the ellipsis lands is the one thing on this page most likely to be wrong offline.
  6. v2's live "In progress" card is not shown. It has a violet left edge and no delete icon, and only ever appears on Drafts. Out of scope for a like-for-like comparison; it has no v1 counterpart.
  7. Screen height is trimmed. min-h-screen is 520px here so both columns fit on one page. Nothing about spacing inside a card is affected.
  8. The count chip does not mean the same thing in both columns — see row 4. This is a real difference in the code, not an artefact of the mock.
