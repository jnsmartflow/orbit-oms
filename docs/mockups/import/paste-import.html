Decisions baked into this mockup

  • Paste is the default tab and sits first. The modal opens with the paste box focused, so the operator's CtrlV lands without a single extra click. The .xlsx path keeps its tab and behaves exactly as it does today.
  • Paste still works from any tab. CtrlV is caught on the modal, not on the text box. If the text looks like the SAP OBD report, the modal jumps to the Paste tab and reads it. If it doesn't, the paste is ignored and nothing changes on screen.
  • Listen only while the modal is open. The orders screen already uses CtrlV to paste an SO number (the hint in that page's footer). A page-level listener would fight it. This one mounts with the modal and unmounts with it.
  • The raw text is never echoed back. 370 KB of pipes tells the operator nothing. What they need is: how many OBDs, how many lines, any problems — which is what the box becomes after pasting.
  • The 001 → 900001 conversion is shown, not hidden. One quiet line plus a struck-through value in the sample rows. If it ever misfires, the operator sees it on screen instead of someone finding bad quantities a week later.
  • Re-pasting replaces. No clear button, no confirm. Paste again and the previous block is dropped — which is also how the error state is recovered from.
  • OBD date auto-fills from the pasted rows instead of staying on today, with the note changed to say where it came from. Manual override stays.
  • Still to decide: after a clean paste, should Preview before import default to on? The operator is already on screen and it costs one click — but it also slows down the fast path this whole change exists to create.
