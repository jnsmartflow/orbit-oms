How it behaves

  • One import at a time. While the pill is running, the Import button is disabled with a tooltip saying an import is already running. Two SAP imports at once on the authoritative path is not something worth finding out the hard way.
  • It survives moving around Orbit — floor, picking, mail orders — because it lives in the header, above the page. It does not survive a hard refresh or closing the tab. The import still finishes on the server; you just lose the result, which you can still find under View Audit.
  • No progress percentage. The server returns once, at the end — it doesn't report progress as it goes. A bar that pretends to know would be a lie, so it just shows movement.
  • Green never auto-hides. The whole point is that you walked away. It clears when you click ✕ or Dismiss, or when you start the next import.
  • Red never auto-hides either, and it can't be cleared by starting another import — you have to open it and look first.
  • Phone notifications are deliberately NOT in this step. You already have Web Push working for picking, so it can be added later. But it only matters if you close Orbit mid-import, and the person pasting is sitting at the screen. Worth doing only if that turns out to be real.
  • Same pill for the .xlsx path. It reads "Importing 98 OBDs" either way — the source appears in the panel, not the pill.
