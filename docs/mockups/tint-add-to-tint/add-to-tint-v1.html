What the popup reads (lookup → matches[])

  • One match → open it. Several → chooser (state 6). Each match carries verdict ok / confirm / refused, reason, invoiceNote, pickerName, trips[] with sentToBilling, isSample, customerMissing, lineCounts, lines.
  • verdict: confirm → amber banner + "Pull anyway" (state 3). refused → red line, no form (state 7). NO_LINES is drawn as state 8, not as a red refusal.
  • isSample true → the toggle shows ON and locked, "Already a sample" (the pull never clears the mark).
  • customerMissing true → operator select disabled, "Add the customer first, then assign".
  • POST body: orderId, lineIds, reasonCode, reasonNotes?, confirmCancelPick?, operatorId?, markSample?.
  • Line quantity: unitQty tins · volumeLine L.
