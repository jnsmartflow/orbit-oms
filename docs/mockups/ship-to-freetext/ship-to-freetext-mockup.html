Rules shown
  • Big centred modal (~720px). Opens on Search dealer with the current ship-to on top.
  • Search dealer = dealer list only (incl. ORB). No challan upload there.
  • Type name = name (or "As per challan") + Area (required, starts at customer's area) + optional copy, up to 3.
  • "As per challan" → name box locks, area still required (decides the route), copy becomes required, Save is off until a file is attached.
  • Every typed ship-to carries the normal ↪ Ship-to changed tag (same as a dealer redirect).
  • Billing + Floor show "As per challan" as the name. Picking (supervisor, picker, push) and the trip sheet show the dealer name + tag; a named site shows as a small "→ site" line.
  • Picking a dealer or Reset to customer clears the typed name and hides its copy (the file stays stored, not deleted).
  • Scope line: Billing = all bills of the SO · Floor = this bill only. Floor refuses a bill already on a trip.
