Mockup only — static HTML, nothing is wired. Admin-only screen: Settings › Hide › Tags (components/admin/hide-settings-content.tsx). Phase 1 is badges and bands. Hold / Slot / Urgent / the ship-to pencil are not here — they are capabilities, not badges, and belong to the per-user access ticks in phase 2.
Grouping: the three instruction-band keys sit in a new Billing bands group. Key dealer, match chip and punched-by are badges, not bands, so they stay in Mail Orders. Say the word if you want all six under Billing bands instead.
Resolution: user > role > everyone. A role exception applies to a multi-role person only if every role they hold hides it — show wins. No admin bypass: you see these switches take effect yourself.
