What changed and why
  1. One form, one field order for New and Edit: Type → Slot → Transporter → Vehicle → Docket → Note.
  2. Transporter comes before Vehicle and starts as Nagadhiraj (124 of the last 165 trips). The vehicle list only shows that transporter's fleet, so a vehicle can never quietly swap the transporter.
  3. Vehicle is a search box. Type any part of the plate or the driver's name — "4266", "gj05bu", "rajubhai" all work. Spaces and dashes ignored.
  4. Vehicle model (Piaggio, Tata Ace…) parked for later — needs a new column + one-time fill.
  5. No helper text on the form — no "optional" labels, no hints, no "default" tags.
  6. Typed plate moved up from the bottom of the list: type a plate that isn't in the master and a Use "…" as typed plate row appears. Transporters with no fleet (DTDC, Diamond…) go straight to typing.
  7. Delivery type and Slot are one-tap buttons, not dropdowns. In Edit, the type sits locked in the header.
  8. Docket field added to New trip (the server already accepts it).
  9. Fields, buttons and focus ring follow CLAUDE_UI §4 / §9 / §10 (38px, violet ring, no uppercase labels).
