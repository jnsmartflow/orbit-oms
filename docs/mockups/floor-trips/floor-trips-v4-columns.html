Every row says when it's due

The slot tabs used to show a time and hide the date, so Wednesday's 10:30 and Thursday's 10:30 sat in one pile. The tabs are gone — now the date lives on the row itself, and a bill promised for Saturday is visible instead of buried.

02

How the Due column reads

Four states, and never a bare time

  • Today · 10:30  — due today, in that window
  • Sat 12 · 12:30  — promised ahead. Blue, so it reads as "not yet"
  • Mon 8 · 12:30 2d  — overdue, with its age
  • no slot  — the engine could not schedule it. Putting it on a trip fixes it

The old tabs showed 10:30 with no date, which is how two different days ended up looking like one queue. That cannot happen now.

No auto / manual marker — on purpose

After this change a bill's slot comes from exactly two places: the engine set it on import, or a trip set it.

And if a trip set it, the trip tag is already sitting in the OBD cell on the same row — L-01 — so the source is visible without a second marker.

Manual slot-picking is gone entirely, so there is no third case left to distinguish.

03

What each column is for

Nine data columns. The same count as before this work started — Picker and # left as Due and KG arrived.

OBD The bill. Carries its trip tag when it's on one, and an age chip when it's carried over. Paste one into search to find it.
Invoice Whether billing has raised it. A bill with no invoice cannot leave the depot — this is the column that tells you.
Ship to The delivery customer. A redirect shows as original → redirect.
Route Which side of town. The first thing you sort a load by.
Due new Date and window it was promised for. Replaces the slot tabs, which hid the date.
Vol Litres. The number the depot talks in.
KG new Weight. What a vehicle's capacity is actually measured in — vehicle_master stores capacityKg.
Art Pieces, typed — 33 D · 44 C. How it stacks in the van.
Status Waiting · With picker · Needs check · Done · Tinting. Everything else about the bill is in the detail panel with the activity trail.

KG might not exist yet. Litres and article counts are already on the bill. Weight may have to be computed from the SKU master, which is a different size of job. So the next prompt checks where weight comes from before building the column — if it turns out to be a computation, that is your call, not an assumption.

04

Upcoming stops being a hidden bucket

Before, bills promised for a later date sat in a collapsed strip at the bottom of the board — "Upcoming 24 — locked until their dispatch day" — and in the current build they disappeared altogether when that strip stopped rendering.

Now they stay in the same list, below a divider, with their date on every row. Nothing to click, nothing to discover, and the divider carries its own totals so you can see at a glance how much is already committed to later in the week.

They can still be put on a trip. If billing promised something for Saturday and a Saturday load is being planned on Thursday, nothing stands in the way — which was impossible while the strip was locked.
