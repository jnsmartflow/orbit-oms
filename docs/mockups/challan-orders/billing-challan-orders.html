Reading this frame

  • Tab pill copies billing-tab-bar.tsx exactly: gray-900 underline + gray-900 count chip when active. No live dot (like Telephonic — nothing here moves by itself often enough). The count is Not billed only — work outstanding, the way the other pills count.
  • Not billed is all dates, oldest first. Age chip: neutral < 3 days, amber 3–6, red ≥ 7 (F3). The paste box takes one SO; Link runs the dealer guard (F1b) and the one-SO-one-challan guard (F5) — the two toasts (bottom-right) are their refusals; the box keeps the typed number with a red border so it can be corrected.
  • Waiting for OBD: a challan with several SOs can be half in — ORB-2026-00005 shows one SO whose OBD has landed and one still waiting. It stays in this band until every SO has its OBD.
  • Billed: ✅ uses the ok tokens, ⚠ the warn tokens — a mismatch is a thing to check, not an error. Click a row to open the side-by-side lines (the ⚠ row is shown open).
  • The red banner is the D11 refusal (OBD already with a picker). The other D11 branch — not yet picked, auto pull-back — would be a plain gray-900 toast: “OBD 9109… pulled back from Floor and linked to ORB-…”.
