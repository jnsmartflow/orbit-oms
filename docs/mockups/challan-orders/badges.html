Challan badge — Picking card + Floor row

An ORB order carries a small CHALLAN badge wherever a bill shows, beside the badges the row already draws. The badge needs no tick. On Floor, Billing’s link shows read-only (“Billed: SO · OBD · Inv”); Picking shows the badge only (M8). Printing the challan is parked (D7) — no print button anywhere in Phase 1.

  • Where it sits: in the caption, after the number, the same slot TINT / BASE / GIFT / HAND use — shrink-0, so the time truncates before the word does.
  • The number: an ORB order has no OBD — the ORB number sits in the OBD slot (D1), so the caption already reads differently; the badge is what says why.
  • Behaviour is unchanged: tap selects, the arrow opens the bill, Assign is the commit. No new violet on the card (CLAUDE_UI §59.9).
  • Second card (checked, Done tab): the badge and nothing else — no “Billed:” line on Picking (M8). The billing state lives on the shared Challan orders screen.
  • The linked SAP OBD itself never appears on Picking (D9).

  • Badge: rides the Ship to cell — where TINT / BASE / GIFT / HAND already sit on this table — so no new column and the four width arrays in floor-table.tsx stay as they are. It goes before the dealer name, not after like its siblings: the cell ellipsises, and at 13% a badge placed after a long name is clipped away (it was, in the first draw of this mockup). In front, the name truncates instead.
  • ⚠ Found while drawing: ORB-2026-00001 is 14 characters against an OBD’s 10, so in the 13% OBD track the trip tag no longer fits beside it. On ORB rows the tag moves to the date line (M2).
  • Invoice cell: empty, as for any bill SAP has not stamped — the ORB row has no invoice of its own. The SAP numbers live on the “Billed:” line.
  • “Billed:” line: a full-width line under the row, only once Billing has linked at least one SO. Before that the row is just the row. With two SOs it lists both: “SO 4409811, 4409840 · OBD 2 · Inv 2”.
  • No Print challan button — printing is parked (D7). The paper design is kept in challan-paper.html for later.
  • The linked SAP OBD never appears on Floor — no row, no Hold tab, no Cancelled tab (D9).
