Challan orders — mockups

Phase 1, non-tint. The depot sends goods on a challan before SAP can bill; the Orbit number ORB-2026-00001 is the challan. Billing later pastes the SAP SO against it, and the SAP OBD that follows is linked, hidden from dispatch and matched line by line. Sample data throughout: MOHAN COLOUR CO (102425), GLOSS · BLACK 500ML × 36.

1
Place Order — create a challan order place-order.html
The desktop cart panel as it ships today, plus a secondary “Create challan order” above Send Email, the three-way Ship to, the confirm step and the “created” toast.
 2
Challan orders — Billing edit view billing-challan-orders.html
The one shared screen (D8) as a tab in Billing, for the edit tick. Four inner tabs — Not billed (ageing, paste SO + Link) · Waiting for OBD (Unlink) · Billed (✅ / ⚠ line match) · History (date range + search, every status) — plus the error toasts and the double-dispatch banner.
 3
Challan orders — view only view-only.html
The same screen and four tabs without paste SO, Link or Unlink (not drawn at all). Switch between its two mounts: a “Challan orders” tab in Floor’s tab bar, and Place Order’s “My challan orders” link.
 4
Picking card + Floor row — the Challan badge badges.html
One Picking card and one Floor row carrying a “Challan” badge. Floor adds the read-only “Billed: SO · OBD · Inv” line; Picking shows the badge only (M8). No print button (D7 parked).
