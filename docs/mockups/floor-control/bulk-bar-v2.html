What changed vs today
  • 8 controls → 4. Mark urgent, Hold, and the split "Change slot + pick slot" pair are gone from the bar.
  • Slot is now one control. One button, one popover holding date + time together. Today it's a label sitting next to a separate button, which reads like two different things.
  • The assign group is one joined unit. Dropdown and button touch, so the eye reads it as a single machine rather than two loose parts.
  • Urgent is a bolt on every row — grey when normal, red when urgent, one click to toggle. Faster than tick-then-scroll-to-bar, and it shows you the current state without selecting anything.
  • Hold moves to the detail panel. Holding is a one-bill decision with a reason behind it, not a sweep.
  • Assign is the only teal thing on the surface — per the one-teal rule.
