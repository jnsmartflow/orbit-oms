## 3. A4 sheet — content rules

**Look:** same as the NTS sheet — JSW logo (data URI + explicit 141×34), "TRIP SHEET", slate address band,
bordered meta strip, enclosed grid, blank filler rows to 20, totals row, 3-cell bottom band, footer.

**Header:** `trips.tripNumber` · date (`tripDate`, UTC getters) · time = `manualDispatchAt` (IST) else dispatch slot window time.
**Meta strip:** Type (delivery type name; mixed trip → "Local + Upcountry", same as `tripMixLabel`) · Vehicle
(`vehicle_master.vehicleNo` else `adhocVehicleNo`) · Driver · Driver mobile (trip snapshots).

**Table — one row per bill, grouped by stop:**

| Column | Rule |
|---|---|
| Stop | 1..N in printed order (NOT `dropSeq` — that is add-order). Printed on the stop's first row only |
| Customer | `trip_drops.customerName` only — the place the truck delivers to (after ship-to change / site). Printed on **every** row of the stop. **No** billed-dealer line, no brackets |
| Area | `trip_drops.areaName`, every row |
| Invoice No | **One number:** `orders.invoiceNo`, else OBD. Never both |
| Articles | Supervisor's typed count `pick_assignments.articleCount`; if null → `import_obd_query_summary.totalArticle` |
| LT / KG | Via `lib/reports/bill-facts.ts` (snapshot totalVolume → orders.volume fallback; KG = SAP gross weight) |

- Gift bill (`materialType` GIFTS): small **Gift** tag, own LT/KG shown grey, adds 0 to LT/KG totals (`loadLitres`/`loadKg`).
- Re-delivery carried on this truck: **Re-del** tag.
- Held and removed bills: hidden.
- Sort: area A–Z → stop (dropSeq) → OBD.
- Totals row: "N stops · N bills", articles (all rows), LT, KG (gifts excluded).
- Bottom band: Transporter = trip's `transporter_master.name` ("—" if none) · Vehicle · Driver (mobile) · Dispatched By · Received By.
- **PROVISIONAL** mark (small, top right) when vehicle missing OR picking not done (`isReady` false). Sharing allowed any time.
- **Hand trips** (`isHand`): no sheet, no Share button.
- Footer: "Generated by Orbit · dispatch record, not a tax invoice".

## 4. Phone screens

**List (`/trip-sheets`)** — Picking-style mobile shell (avatar · violet title · page-grid · search), date pill,
cards: trip no (small mono) · vehicle (bold) + time right · driver first name · area label (+N) · pills
(stops, bills, litres) + Ready/Picking chip. Bottom tab bar (All / Ready / Picking) on this screen only.

**Inside a trip (`/trip-sheets/[id]`)**
- Masthead: back · trip no · grey sub-line (vehicle · driver first name · time).
- **No bottom tab bar.**
- **No sheet preview on screen** and **no Print button** on phone.
- **Floating "Share on WhatsApp"** button fixed at bottom; content padded so last card is visible.
- Stop header: numbered circle · stop name · area (grey, right).
- Bill card: line 1 = invoice no (else OBD) + Gift/Re-del tag · line 2 **only when the billed dealer differs from the
  delivery point** → violet "↪ Ship-to changed" mark + "Bill of {dealer}" · line 3 = pills (Art, L, kg).
- ⚠ Build note: decide "differs" on **ids** (bill-to customer vs effective delivery point), not names — the mockup
  compared names only.

**Share:** captures the A4 sheet as PNG (same-document hidden render, never iframe; logo data URI + explicit
width/height), `navigator.share` with files on phone; desktop = download PNG + copy caption.

**Caption:**
```
🕐 {time 12h} · {tripNumber}
{driver first name} {mobile}
{N} stops · {unique areas, comma-joined}
```
